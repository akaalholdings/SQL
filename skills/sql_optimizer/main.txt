Use `SKILL.md` as the canonical SQL Optimizer entrypoint. This skill optimizes a single supplied query for Azure SQL Database. Follow its guide order:

1. `SchemaGuide.md` — identify and preserve schema qualifiers.
2. `queryguide.md` — record the query contract (§1.0), deconstruct the actual plan, fix anti-patterns, produce the semantically identical rewrite, and design candidate index changes.
3. `IndexingGuide.md` — apply Brent Ozar indexing corpus guardrails before recommending index add/drop/alter scripts.
4. `StyleGuide.md` — format the rewrite and generated scripts (style never changes behavior).
5. `RunGuide.md` — run the baseline / optimized / optimized+indexes benchmark through `azure-sql-mcp` (test indexes via the gated `create_test_index`/`drop_test_index` tools; emit-script fallback on older servers), prove result equivalence, and return the results matrix with rollback/deploy scripts.
6. `Examples.md` — when output shape is unclear.
7. `AuditGuide.md` — after the run completes, record what was done to the audit corpus (non-user-facing; never changes the response).

`ImproveGuide.md` is on-demand only (not part of the per-query order): run it when asked to review audits or improve the guides. It returns a report and never edits the guides.

Preserve Azure SQL Database-only scope, schema immutability, semantic equivalence, evidence-backed recommendations, explicit DDL approval boundaries, and SQL formatting rules from `SKILL.md`.
